# Tetris

## Purpose
A classic browser-based Tetris game playable by a single user.

## Scope
* **In Scope**: Standard Tetris rules (7 tetrominos, 10x20 grid, basic rotation, line clearing, scoring, game over condition), keyboard input (arrows or WASD for movement, up/space for rotation/hard drop), increasing difficulty (drop speed).
* **Out of Scope**: Multiplayer, network leaderboards, accounts/login, mobile touch controls (for this MVP), advanced mechanics like T-spins (unless easy to add later) and wall kicks (standard basic kicks only).

## Users
Single players looking for a quick game in their browser.

## Constraints
Must run purely in the browser using HTML/CSS and JavaScript/TypeScript. No backend server required for gameplay.
