# Layout

## Source Code
*   `index.html`: The main entry point, containing the canvas element and UI layout.
*   `style.css`: Styles for the game container, canvas, and UI overlay.
*   `src/game.js`: The main game loop and controller logic.
*   `src/model.js`: The Game Engine logic (grid, piece state, collision, scoring).
*   `src/view.js`: The Renderer logic (drawing to the canvas).
*   `src/constants.js`: Configuration values (grid size, colors, shapes).

## Tests
*   `tests/`: Directory for any unit tests (e.g., testing line clear logic or collision independently).

## Documentation
*   `docs/dev/`: SDD Manager development documents.
