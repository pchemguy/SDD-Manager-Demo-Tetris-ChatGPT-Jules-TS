# Milestone 2.4 Report

## Scope
- T-028: Implement standard SRS Wall Kicks
- T-029: Implement exact 1-gravity-interval Lock Delay

## Evidence
- `constants.js` now includes the complete SRS wall kick translation table mapping rotations state transitions.
- `Tetromino.getWallKicks()` looks up the standard offsets for the rotation requested.
- `GameState.rotatePiece()` was overhauled to iterate through the wall kick offsets provided by `Tetromino`. If standard rotation fails, it tests the alternate positions, succeeding if one is valid.
- `GameState.update()` correctly splits logic: when falling, it applies standard gravity. When resting on a surface, it ceases gravity and instead runs `lockDelayAccumulator`.
- `GameState.lockDelayLimit` is strictly tied to the current gravity interval. 
- `GameState.resetLockDelay()` is invoked upon successful horizontal movement or rotation to give the player more time, but capped by `maxLockMoveResets` (15) to prevent infinite stalling ("lock down" rule).
- Verified in-browser: Pieces don't lock instantly upon touching the stack. The player has time to slide them under overhangs. Rotating pieces near the wall successfully kicks them away from the boundary rather than simply failing.
